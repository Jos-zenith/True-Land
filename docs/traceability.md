# Traceability: requirement → code → test

Requirement IDs are defined in [requirements.md](requirements.md). `src/docs.test.ts` checks this
matrix on every test run. It fails if a referenced file or symbol no longer exists, if a referenced
test title is missing, or if a row has neither a test nor an explicit "No automated test" status.

Status vocabulary:

* **Implemented**: built and covered by the automated tests listed.
* **Implemented (demo)**: works end to end on labelled demo data or fixtures only.
* **Interface only**: the integration boundary and contract are built and tested against a fake; the real external system is not connected.
* **Not verified**: there is no evidence either way.

Test reference format: `file :: title fragment`.
